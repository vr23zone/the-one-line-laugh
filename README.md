# The One-Line Laugh

A tiny Node 22 program for the make.fun bounty "The One-Line Laugh". It writes a single
funny line (one sentence, 104 characters) to `/output/entry.txt`:

> I asked my smart fridge what's for dinner and it said 'you have 14 sauces and no plan' — honestly, fair.

Run it with `node main.ts`. It uses only the Node standard library, takes no input, and
makes no network calls.
